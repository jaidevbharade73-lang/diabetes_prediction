# AI Diabetes Prediction System

An interactive Machine Learning web application built with Python, Scikit-Learn, and Gradio to predict diabetes risk based on medical parameters.

## 🚀 Features
* *Machine Learning Model:* Trained using Random Forest Classification on health indicators.
* *Interactive UI:* Clean, responsive web interface built with Gradio (featuring inputs for Glucose, BMI, Age, Insulin, etc.).
* *Instant Predictions:* Real-time output showing diabetes risk assessment.

## 📁 Repository Structure
* app.py: Main python script containing the Gradio web interface and inference logic.
* diabetes_model.pkl: Pre-trained Random Forest model weights.
* requirements.txt: Python package dependencies for execution.
